# Новостное агентство + Lenta.ru

Веб-приложение на **FastAPI**, которое при обращении к корню сайта загружает главную страницу [https://lenta.ru/](https://lenta.ru/), разбирает HTML в структуру новостей и отдаёт страницу на основе шаблона **Jinja2** (`templates/index.html`). Статические файлы (стили, скрипты, изображения) раздаются из каталогов проекта.

Если загрузка или разбор невозможны (защита сайта, смена вёрстки, сетевые ошибки), пользователь видит **запасные статические данные** из `parsers/fallback_data.py` — приложение не падает с необработанным исключением на маршруте `/`.

---

## Состав проекта и технологии

| Компонент | Назначение |
|-----------|------------|
| **FastAPI** | HTTP-сервер, маршрут `GET /`, подключение статики |
| **Uvicorn** | ASGI-сервер для запуска приложения |
| **Jinja2** | Рендеринг `templates/index.html` |
| **BeautifulSoup4 + lxml** | Разбор HTML главной и страниц статей |
| **curl_cffi** | HTTP-запросы с имитацией TLS/отпечатка браузера Chrome (`impersonate="chrome110"`) |
| **Playwright** | Загрузка страницы в настоящем Chromium (системный Chrome), сохранение куки в `cookie.json` |
| **python-dotenv** | В зависимостях есть пакет; текущий `main.py` **не вызывает** `load_dotenv()` — при необходимости подгрузки `.env` это нужно добавить в код вручную |

Исходная вёрстка страницы (колонки «Новости дня», центральный блок, «Самые читаемые») сохранена; динамически подставляются только данные новостей.

---

## Требования к окружению

- **Python 3.10+** (рекомендуется актуальная стабильная ветка 3.x под вашу ОС).
- **Windows**: проект изначально заточен под путь к Chrome по умолчанию (см. раздел про `CHROME_PATH`). На Linux/macOS путь к браузеру нужно задать явно, если используете режимы `playwright` или `hybrid`.
- Для режимов **`hybrid`** и **`playwright`** нужен установленный **Google Chrome** (исполняемый файл `chrome.exe` / `chrome`), так как Playwright запускает браузер по указанному пути, а не только встроенный движок без системного Chrome.

## Установка (Windows, PowerShell)

### 1. Клонирование / каталог проекта

Перейдите в корень репозитория (где лежат `main.py`, `requirements.txt`, папка `parsers/`).

### 2. Виртуальное окружение

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Если политика выполнения скриптов запрещает активацию, временно для текущего пользователя:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

### 3. Зависимости Python

```powershell
pip install -r requirements.txt
```

Содержимое `requirements.txt` и роль пакетов:

- `fastapi`, `uvicorn` — веб-фреймворк и сервер.
- `jinja2`, `aiofiles` — шаблоны и при необходимости асинхронная работа с файлами (FastAPI может использовать aiofiles для стриминга файлов).
- `curl-cffi` — запросы к Lenta.ru с заголовками и опциональными куками.
- `playwright` — программный запуск Chrome для получения HTML и `storage_state`.
- `beautifulsoup4`, `lxml` — парсинг HTML.
- `python-dotenv` — опционально для будущей загрузки переменных из `.env`.

Установка браузеров через `playwright install` для этого проекта **не является обязательной основой**: код использует **`executable_path`** к установленному Chrome, а не только скачанный Playwright Chromium (если только вы сами не меняли `playwright_parser.py`).

## Запуск приложения

```powershell
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

- **`--reload`**: перезапуск при изменении кода (удобно в разработке; в продакшене обычно отключают).
- **`main:app`**: объект `app` в файле `main.py`.

Откройте в браузере: **http://127.0.0.1:8000/**

Логирование в консоли: уровень **INFO** (`logging.basicConfig` в `main.py`). При падении парсинга в лог пишется исключение и текст про переход на fallback.

## Маршруты и статика (FastAPI)

В `main.py` объявлено:

- **`GET /`** — единственный динамический маршрут: вызывается `load_news()`, результат передаётся в `templates.TemplateResponse("index.html", {"request": request, **data})`.
- Статические префиксы (монтируются через `StaticFiles`):
  - **`/styles`** → каталог `styles/`
  - **`/Img`** → каталог `Img/`
  - **`/js`** → каталог `js/`

Шаблон подключает ресурсы вида `styles/...`, `Img/...` — они резолвятся относительно хоста приложения, то есть уходят на эти mount’ы.

Заголовок приложения в OpenAPI: **`Новостное агентство + Lenta.ru`** (`FastAPI(title=...)`).

## Переменные окружения

### `LENTA_PARSER`

Определяет, **каким способом** получить HTML главной Lenta.ru перед парсингом. Чтение: `os.environ.get("LENTA_PARSER", "hybrid").lower()`.

| Значение | Поведение |
|----------|-----------|
| **`hybrid`** (по умолчанию) | Если файл `cookie.json` отсутствует или невалиден — вызывается Playwright (загрузка страницы, запись `storage_state`). Затем HTML запрашивается через **curl_cffi** с куками из файла. Если ответ похож на challenge или слишком короткий — снова Playwright для обновления кук, повторный запрос curl. Реализация: `parsers/hybrid_parser.py`. |
| **`curl`** | Только `parsers/curl_parser.fetch_lenta_html()` без предварительного Playwright. Куки в запрос главной не подмешиваются из файла в том же виде, что в hybrid (логика hybrid читает `cookie.json` отдельно). В `main.py` для обогащения карточек дополнительными запросами к статьям куки **не передаются**, если режим ровно `curl` **или** `cookie.json` невалиден — см. условие с `cookies_dict_for_lenta()` и `cookies_file_valid()`. |
| **`playwright`** или **`pw`** | HTML главной берётся только через `parsers/playwright_parser.fetch_lenta_html()` (полный цикл браузера при каждом заходе на `/` внутри `load_news()` — тяжелее по ресурсам). |

Примеры PowerShell:

```powershell
$env:LENTA_PARSER = "curl"
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

Сброс к значению по умолчанию (в новой сессии переменная просто не задаётся):

```powershell
Remove-Item Env:\LENTA_PARSER -ErrorAction SilentlyContinue
```

### `CHROME_PATH`

Путь к исполняемому файлу **Google Chrome**. Используется в `parsers/playwright_parser.py`:

- Если переменная **не задана**, по умолчанию:  
  `C:\Program Files (x86)\Google\Chrome\Application\chrome.exe`
- Если Chrome установлен в `Program Files` (64-bit), задайте явно, например:

```powershell
$env:CHROME_PATH = "C:\Program Files\Google\Chrome\Application\chrome.exe"
$env:LENTA_PARSER = "playwright"
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

При отсутствии файла по пути Playwright выбросит `FileNotFoundError` с текстом «Chrome не найден по пути …».

## Вспомогательные файлы в корне проекта

### `cookie.json`

Файл в формате **Playwright `storage_state`**: JSON с массивом `cookies` и др. Записывается после успешного захода Playwright на главную Lenta.ru.

Проверка валидности (`parsers/cookie_store.py`):

- файл существует, размер не меньше 12 байт;
- JSON парсится;
- в `cookies` есть хотя бы одна запись с доменом, содержащим `lenta`.

Из этого файла для **curl_cffi** собирается словарь имя→значение куки только для доменов, оканчивающихся на `lenta.ru` (`cookies_dict_for_lenta`).

### `user_agent_pc.txt`

Необязательный файл: построчно перечислены User-Agent строки. Пустые строки и строки с `#` в начале игнорируются. Если файла нет, используются встроенные дефолтные UA из `parsers/utils.py`. Случайный выбор строки — для заголовков curl и для Playwright-контекста (`pick_user_agent`).

### Задержки между запросами

`parsers/utils.random_delay(min_s=0.35, max_s=1.25)` — случайная пауза перед HTTP-запросами и перед запуском Playwright, чтобы не долбить сайт с максимальной частотой.

## Поток данных: от запроса пользователя до HTML

1. Пользователь открывает **`GET /`**.
2. Вызывается **`load_news()`** в `main.py`.
3. В зависимости от `LENTA_PARSER` получается строка HTML главной (`curl` / `playwright` / `hybrid`).
4. HTML передаётся в **`parse_lenta_home(html)`** (`parsers/lenta_parse.py`).
5. Если парсинг успешен, выполняется **обогащение** (дополнительные GET на страницы отдельных статей через `curl_fetch_url_html`, см. ниже).
6. Словарь с ключами `daily_news`, `main_hero`, `main_grid`, `popular_featured`, `popular_list` передаётся в шаблон.
7. При любой ошибке на шагах 3–5 в лог пишется исключение, возвращается **`get_fallback()`**.

## Разбор главной страницы: `parse_lenta_home`

### Предварительные проверки

- Если длина HTML **меньше 5000** символов — `ValueError("Слишком короткий ответ")`.
- Если срабатывает **`is_bot_challenge_page(html)`** — поиск подстрок (без учёта регистра в нижнем регистре текста): `just a moment`, `cf-browser-verification`, `проверка браузера` — тогда `ValueError("Страница защиты (challenge)")`.
- Дальше разбор через **BeautifulSoup** с парсером **`lxml`**.

### Верхняя лента «Новости дня» — `daily_news`

- Контейнер: **`.topnews`**.
- Ссылки: **`a[href^='/news/']`**, **`a[href^='/articles/']`**, без дубликатов по `href`, до **12** штук, в ответе используются **первые 6**: `daily[:6]`.
- Заголовок: текст ссылки; если в конце есть время вида **`… 12:34`**, оно отрезается регулярным выражением (время в `time_display`).
- Категория для этого блока: **`"Новости"`**.
- Картинка: эвристика **`_pick_image_url`** — `img` с классами `picture__image`, `card-big__image`, `card-mini__image` или любой `img[src]`, с учётом `data-src`, `data-original`, первого URL из `srcset`, префикса `//` и `urljoin` к `https://lenta.ru`.

Если после разбора в **`daily`** оказалось **меньше 4** элементов — **`ValueError("Не удалось извлечь ленту новостей")`**.

### Центральная секция — `main_hero` и `main_grid`

- Секция: **`.main-page__section`**.
- **Hero**: первая ссылка **`a.card-big`** с `href` на `/news/` или `/articles/`, разбор через **`_from_card_big`** (заголовок из `h3.card-big__title` или общий текст, время из `time`, рубрика из `span.card-big__rightcol`, картинка из карточки или родителя/секции).
- **Сетка**: до **6** кандидатов из:
  - `a.card-feature`,
  - `a.card-big._longgrid`,
  - `a.card-big._topnews`  
  (все с префиксами `/news/` или `/articles/`), дубликаты по абсолютному URL отбрасываются.
- Если в сетке **меньше 4** карточек, добирается из **`a.card-mini`** с теми же префиксами href.

Дополнительно для hero и элементов сетки вызывается **`_with_article_image`**: если у элемента нет `image_url`, ищется ссылка с тем же `href` в дереве страницы и из неё извлекается картинка.

**Заполнение недостающего:**

- Если **hero** не найден, но `daily` не пуст — hero = **копия первого элемента** `daily`.
- Если в **сетке** меньше 4 элементов — в сетку по очереди добавляются элементы из `daily` (не совпадающие по URL с hero и уже добавленными), пока не наберётся 4.

### Блок «Самые читаемые» — `popular_featured` и `popular_list`

- Контейнер: **`div.slider._popular`**.
- Карточки: в первую очередь **`a.card-big._article`**, иначе **`a.card-big._popular`**; во внутреннем цикле собирается до **7** элементов.
- **`popular_featured`** — **первый** элемент; **`popular_list`** — **следующие три** (срез `items[1:4]`).

Если популярный блок пуст:

- `popular_featured` может взяться с **7-го** элемента `daily` (индекс 6), иначе с **последнего** элемента `daily`.
- `popular_list` добирается из хвоста `daily` и циклически из начала `daily`, избегая дубликатов URL с featured.

К **`popular_featured`** также применяется **`_with_article_image`**.

### Итоговый словарь `parse_lenta_home`

Возвращается объект с ключами:

- **`daily_news`**: ровно **6** записей (или меньше только если логика выше не сработала — при валидном успехе это 6).
- **`main_hero`**: один словарь или `None` (шаблон всё равно ожидает поля — при fallback они заданы).
- **`main_grid`**: не более **4** записей (`grid[:4]`).
- **`popular_featured`**: одна запись или `None`.
- **`popular_list`**: не более **3** записей.

## Обогащение данными со страницы статьи (`main.py`)

После успешного `parse_lenta_home` сервер **не ограничивается** HTML главной: для части карточек выполняются дополнительные запросы **`fetch_url_html(url, cookies=cookies)`** (curl_cffi, те же заголовки и таймаут 45 с).

**Куки** для этих запросов передаются, если режим **не** `"curl"` **и** `cookie.json` валиден — иначе `cookies=None`.

### Блок «Самые читаемые» (крупная карточка)

Для **`popular_featured`** по URL статьи:

- если нет **`lead`** или **`image_url`** (на главной) — скачивается HTML статьи;
- **`lead`**: `extract_first_sentence` — первое «длинное» предложение из параграфов в контейнере `.topic-body__content`, `.topic-body`, `article`, `.b-topic__content` или всего документа;
- **`image_url`**: `extract_article_image_url` — приоритетно `img.picture__image[src]`, иначе `figure img`, `article img` (часто это `detail_*.jpg`);
- **`date_display`**, **`time_display`**, **`datetime_iso`**: `extract_article_published` — сначала `meta[property='article:published_time']`, иначе `time[datetime]`; человекочитаемая дата в формате «день месяц_родительный падеж год» и время `HH:MM`.

Ошибки обогащения **глотаются**: главная страница не ломается, лид может стать пустой строкой.

### Центральная сетка из четырёх карточек

Для **первых четырёх** элементов `main_grid`:

- если нет **`image_url`** — пробуется картинка со страницы статьи;
- дата/время публикации — те же функции, что и для popular.

Исключения на отдельной статье **игнорируются** (пустой `except`).

### Hero главной новости

Для **`main_hero`** по URL статьи подтягиваются только **дата/время** публикации (`date_display`, `time_display`, `datetime_iso`).

## Поля одной новости (элемент списка / карточки)

Минимальный набор полей, который формирует **`_news_item`** в `lenta_parse.py`:

| Поле | Описание |
|------|----------|
| **`title`** | Заголовок; если пусто, подставляется `"Новость"`. |
| **`url`** | Абсолютная ссылка на `https://lenta.ru/...` через `urljoin`. |
| **`category`** | Рубрика; по умолчанию `"Новости"`. |
| **`time_display`** | Короткое время, часто `HH:MM`, или пустая строка. |
| **`image_url`** | URL картинки или пустая строка. |
| **`lead`** | Лид/первое предложение; для верхней ленты обычно пусто, для popular может заполниться при обогащении. |

После обогащения могут появиться:

| Поле | Описание |
|------|----------|
| **`date_display`** | Дата для вывода (например, «12 мая 2026»). |
| **`time_display`** | Время публикации статьи. |
| **`datetime_iso`** | Сырое ISO-время из меты/тега `time` (для атрибута `datetime` в шаблоне). |

Шаблон **`templates/index.html`** использует:

- цикл **`{% for news in daily_news %}`** — боковая колонка;
- **`main_hero`** — большая центральная карточка;
- цикл **`{% for news in main_grid %}`** — четыре карточки с подстановкой заглушек-картинок `Img/news-1.png` … если `image_url` пуст;
- **`popular_featured`** и цикл **`{% for news in popular_list %}`**.

У части блоков в шаблоне остались **статические** вставки (дата в шапке, рекламные баннеры) — они не завязаны на парсер Lenta.

## Запасные данные: `get_fallback()`

Файл **`parsers/fallback_data.py`**. Возвращает тот же набор ключей, что и успешный парсинг, но с **фиктивными** заголовками и ссылками на **`https://lenta.ru/`** (или локальные пути к картинкам в `Img/` для части карточек). Нужны, чтобы страница всегда открывалась и выглядела целостно при недоступности источника.

## Типичные проблемы и диагностика

### 1. Страница защиты (Cloudflare и аналоги)

Симптомы: в логе сообщение про challenge, на экране — fallback-новости, не совпадающие с текущей лентой.

**Что сделать:** переключиться на **`hybrid`** или **`playwright`**, убедиться, что Chrome доступен по `CHROME_PATH`, дождаться создания/обновления `cookie.json`, повторить запрос.

### 2. «Слишком короткий ответ» / «Не удалось извлечь ленту новостей»

Значит HTML неполный или Lenta изменила классы/структуру под селекторы в **`parsers/lenta_parse.py`**.

**Что сделать:** повторить позже; сменить режим `LENTA_PARSER`; при постоянной поломке — править селекторы в коде под актуальную вёрстку.

### 3. Ошибка «Chrome не найден»

Задать корректный **`CHROME_PATH`** до реального файла Chrome.

### 4. Понять, живой парсинг или fallback

Сравните заголовки на странице с текущей главной Lenta.ru в браузере. Либо временно добавьте лог в `main.py` в ветку `except` перед `get_fallback()` (для отладки; в продакшене уберите).

## Замечания по использованию парсинга

Сайт **Lenta.ru** принадлежит правообладателю; HTML и новости защищены авторским правом. Этот проект предназначен для **обучения и локальной демонстрации**. Коммерческое или массовое автоматическое скачивание может нарушать правила сайта и законодательство. Соблюдайте разумные интервалы между запросами (в коде уже есть случайная задержка).

---

## Краткая шпаргалка команд

```powershell
# Установка и запуск
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload --host 127.0.0.1 --port 8000

# Режим только curl
$env:LENTA_PARSER = "curl"

# Свой Chrome
$env:CHROME_PATH = "C:\Program Files\Google\Chrome\Application\chrome.exe"
```

После запуска откройте **http://127.0.0.1:8000/** .
